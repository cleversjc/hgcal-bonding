# 稳定版 1.1.0

现有 `/stable-v1/` 入口保留。功能来自开发版提交 `29a4a9149aaa528a326e69b0c245548ef47e1ed7`，包含 OGP 编号对照、PDF 兼容读取、连续检查、特殊处理、逐根拉力、总体记录和完整 ZIP／JSON 备份。

首次启动会把本机稳定版 1.0.0 数据复制到独立的新稳定库，并保留升级前快照。开发版的记录可通过完整备份手动导入。稳定与开发的缓存、记录和界面偏好各自保存。

在「映射与资料」可导出升级前快照，也可带当前记录回到稳定版 1.0.0。旧版可继续编辑它支持的异常记录。返回新版后可查看 OGP、总体记录、新旧历史和原图。单独打开旧版入口时只能浏览旧数据；从新版明确切换后才可继续保存。首次迁移失败时，旧版记录仍可从启动提示的入口继续使用。

上一稳定版的原始目录树为 `adf64a632c982da2c3083139e8a0c8f2df220761`。候选将其保留在 `previous-stable/`，并为回退入口加上独立缓存、返回链接和写入检查。
