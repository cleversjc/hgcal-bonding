## 核心功能
- 正面 Cell → Wire、Wire → Cell 双向精确查询；支持模块图点选。
- OGP 清单：导入 HGCal YOLO PDF / 预处理 JSON，按 Module ID 分组、Wire 升序。每条检测默认取当前 LD V3 映射中的第一根 Wire，完整保留原始检测图与红色标注。
- OGP 导入先解析、预览，明确确认后才写入本机。重复 Cell / Wire 保留独立检测行并提示重复 Wire；检查状态为待确认、正常、确认异常。
- Wire 可手动修正；原始 Wire、映射快照、当前 Wire、修改人、时间、原因和历次检查备注均保留。YOLO confidence 仅表示模型检测置信度，不是严重程度或实际漏胶概率。
- 背面按 H / G / L / K / J / I 六个位置记录，每组计划 5 根，不录入 wire 编号。
- 异常记录：异常类型、线数、照片、处理状态、作废与处理时间线。
- 拉力测试：逐根 Wire 保存拉力值（gf）及测试端点，不再把一个拉力值关联到整个 Cell。旧版记录的单值拉力仍保留为历史字段。
- 总体 Bonding 情况：按模块整体、正面或背面记录整体状态、记录人、备注和照片；独立于 Cell 异常，不计入异常数量。
- 数据：免登录，本机 IndexedDB 保存；JSON 完整备份 / 恢复，异常和总体情况分别导出 CSV。
- 离线：首次联网打开并显示“离线已就绪”后，可通过已安装的主屏幕 App 离线查号和记录。

## 使用
1. 选择或新建 Module ID。
2. 正面选择 Cell → Wire 或 Wire → Cell 查询；背面点选六个位置。
3. 新增异常时，逐行填写拉力测试，例如 `W403, 5.2, Heel`，每行对应一根 Wire。
4. 在“异常记录”页面点击“总体情况”，记录整体 bonding 状态并附上 overview 照片。
5. 定期导出完整 JSON；照片包含在 JSON 中。异常 CSV 和总体情况 CSV 分别导出。
6. 在“OGP 清单”选择报告及导入人 → 解析并预览 → 核对每页模块归属和原图 → 勾选后确认保存。处理完一个奔驰标，直接点该行的“确认修改完成”，该行立即从默认“未完成”清单消失；不用进入表单、填写备注或再次确认。点图可放大，放大界面也可直接完成。
7. 通过“清单筛选 → 已完成”查看完成记录和原图，误点可“恢复到未完成”。需要改 Wire 或补充备注时再打开相应入口。

## OGP 一键完成（2026-11-04 更新）

“确认修改完成”独立于待确认 / 正常 / 确认异常的检查结果；点击不会自动改判为正常，不会清空原图、Wire 或已有备注。完成时间自动记录，记录人沿用该模块记录人；完成与恢复操作追加到历史。未设置完成信息的旧记录继续作为未完成项显示。

JSON 完整备份包含完成信息、历史与原图。CSV 根据当前清单筛选导出，并增加 `completed_at` / `completed_by` 列；选择“全部记录”可一起导出完成与未完成项。开发版离线缓存版本同步更新，`stable-v1/` 保持冻结。

## OGP 支持范围与预处理

浏览器支持带 `HGCal YOLO Leakage Report - 320…` 标题、`cell N conf 0.xx` 文字标签和一图一标签网格的报告。续页仅沿用同一文件上一页的 Module ID；第一页缺标题、标签与图片数量不符、无法唯一配对、扫描件、旋转 / 倾斜图片及不支持的组合会拒绝导入，不猜测对应关系。该实现可处理同类报告，并非任意 PDF / OCR 解析器。目前真实报告验收样本是 `glue_leakage_1104.pdf`。

PDF.js 5.6.205 与 worker 随开发版缓存，无 CDN 依赖。浏览器按图片的原始分辨率无损渲染完整图块为 PNG，保留红色标注与周边结构；这不是原 JPEG 编码字节的复制。样本 121 张图均为 640×480，完整 JSON 约 71 MB。手机空间或内存受限时，优先在电脑上预处理后导入 JSON：

```text
python -m pip install pymupdf
python scripts/preprocess_ogp.py glue_leakage_1104.pdf glue_leakage_1104.ogp.json --assets inspection-images
```

预处理工具也面向上述文字网格版式；其他版式需要适配与重新验证。无额外 PDF 矢量 / 注释覆盖时，它直接保留原始 JPEG / PNG 字节；否则无损渲染完整图块。输出的独立 JSON 自带所有图片字节，样本约 9.35 MB，无需同时选择图片目录。`--assets` 仅为额外检查 / 归档图片。

浏览器 PDF 上限为 30 MB / 60 页 / 2000 条检测，单次原图编码数据上限 80 MiB；OGP 预处理 JSON 上限 100 MiB。新版完整备份恢复支持 JSON / ZIP，输入文件上限 300 MiB，ZIP 展开内容上限 512 MiB / 10000 个文件；较大数据请按模块恢复。上一版入口的 JSON 文件选择上限保留为 100 MiB；应用内带记录切换不经过文件选择。设备配额不足时保存会失败并保留现有记录。清单不自动创建 Bonding 异常，不自动判定流转或合格。

## OGP 数据与导出

- 清单、来源 PDF 的 SHA-256、页码 / 项序号、映射快照、修改历史和完整图片均保存在开发版 IndexedDB；记录与图片分开保存，不会上传报告或生产数据。
- 重复检测具有独立行 ID；字节完全相同的不可变图片可共用图片 ID。重复 Wire 按同一 Module ID 下的当前 Wire 判断，跨导入批次也会提示；手动修正后重新判断。
- 清单 CSV 包含行 ID、图片 ID、原始 / 当前 Wire、YOLO confidence、状态、备注、来源与修改历史。CSV 不含图片字节；导出“完整 JSON 备份”才是可恢复的全量数据。
- 备份沿用 schema-v1 的可选扩展字段 `ogpImports`、`ogpRows`、`ogpImages`。旧备份缺少这些字段仍可恢复；同 ID 导入批次保留本机版本，新批次及关联图片一并合并，校验失败不写入。

## 本地数据与兼容性
应用不要求账号，不会把生产记录上传到 GitHub。各设备不自动同步。旧版 JSON 备份可恢复；旧异常中的 cell-level 单值拉力继续保留，旧备份没有总体记录列表时按空列表处理。逐根拉力结果和总体记录均写入 JSON 备份。

## 更新与离线
更新后保存表单，关闭旧版所有页面 / 桌面窗口，再联网重开正式地址。服务工作线程版本与 mobile-app.js 中的版本号必须一致。更新不清除 IndexedDB。
