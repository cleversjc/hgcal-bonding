# HGCAL Bonding 工作台

手机和电脑均可使用的 LD V3 bonding 查询与异常记录工具。

- 正面：Cell → Wire、Wire → Cell 双向精确查询；也可点击模块图选择 Cell。
- 背面：按 H / G / L / K / J / I 六个位置记录，每组计划 5 根，不录入 wire 编号。
- 异常：记录异常类型、计划 / 实际线数、阶段、拉力、备注和照片；支持待处理、待复检、已关闭、已作废及处理时间线。
- 数据：免登录，记录和照片保存在当前设备的 IndexedDB；JSON 完整备份 / 恢复，CSV 汇总导出。
- 离线：首次联网加载并显示“离线已就绪”后，可通过已安装的主屏幕 App 离线查号和记录。

正式地址：https://cleversjc.github.io/hgcal-bonding/

## 使用

1. 选择或新建 Module ID。
2. 正面选择 Cell → Wire 或 Wire → Cell，输入编号或点选模块图。
3. 背面切换到背面，点选六个位置之一。
4. 选择位置后新增异常，填写异常类型、线数、照片和备注。
5. 在异常记录中更新处理状态；误录记录可标为“已作废”。
6. 定期导出完整 JSON。卸载、清除网站数据或换设备前先备份。

## 本地数据与兼容性

应用不要求任何账号，不会把生产记录上传到 GitHub。不同设备和不同浏览器配置文件之间不会自动同步。JSON 备份包含模块、异常、照片和处理历史。旧版本备份中可能含有 OGP 历史字段；新版不再提供 OGP 查询、确认或展示功能，但恢复时会兼容并保留这些旧字段，不会要求清除本机数据。

## 更新与离线

更新后保存正在填写的内容，关闭旧版所有页面 / 桌面窗口，再联网重新打开正式地址。服务工作线程版本与 mobile-app.js 中的版本号必须保持一致。更新不清除 IndexedDB 记录。
